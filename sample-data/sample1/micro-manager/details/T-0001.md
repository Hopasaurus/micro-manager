# T-0001 — Replace this with a real item

## Context

This file exists to demonstrate the detail-file convention: `T-0001` in
[backlog.md](../backlog.md) carries `detail:details/T-0001.md`, and that path
points here. The `id` and `title` in the frontmatter above match the item line
exactly — [check.sh](../check.sh) enforces that, so an item can't be renamed
without its detail file following along.

Delete this file and the seeded items when you start using the system for real.

## Requirements

Anything that doesn't fit on the item line goes here — prose, tables, pasted
logs, code blocks, checklists that aren't subtasks. There's no length limit and
no required shape beyond the frontmatter; the headings in
[_template.md](_template.md) are a starting point you're free to rearrange.
