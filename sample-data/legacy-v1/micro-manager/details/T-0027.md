# T-0027 — Round-trip tests

## What is covered

`mm/roundtrip_test.go`:

- **Every fixture file** (69) and **every repository file** (50) parses and
  writes back byte-identical — broken fixtures included, because the tool has to
  be usable on a directory that is already wrong.
- **A no-op writes nothing**: a `--move` to the current position, an update
  setting a field to the value it already holds, and a `--wip` to the current
  limit all produce no write and no mtime bump.
- **An edit touches only its own line.**
- **Unregistered fields survive every transition**: add → move → start → update
  → pause → finish, with order preserved.

## A stale test that was skipping, not passing

`write_test.go` had its own `TestRoundTripRealRepositoryFiles` pointing at
`../../../sample1/micro-manager` and friends. Those paths moved under
`sample-data/` and the test skips on a read error, so it had been quietly
skipping since the move rather than failing — the failure mode of `t.Skipf` on a
missing path. It was strictly superseded by `TestRoundTripTheRepository` (same
directories, plus `details/`), so it was removed rather than repaired.

Worth remembering: a skip-on-missing-fixture guard makes a test survive being
wrong. The new test logs the file count it actually covered, so a silent skip is
visible in `-v` output.
