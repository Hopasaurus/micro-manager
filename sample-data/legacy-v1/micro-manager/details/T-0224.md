# T-0224 — Columns: decide how a custom stage gets a theme color

Open question 8 in notes/add-columns.md (§3F). spec-gui.md §8.3's state.* color tokens are a closed set of five, matched to the built-in columns. A custom stage (review, qa) has nowhere to hang a color. Candidates: a shared state.custom fallback token, a dynamic state.<slug> token (breaks the 'every token REQUIRED' model), or documented fallback to accent.base. Leaning toward the accent.base fallback.

Answer: dynamic per state color config available with fallback to accent.base
