# T-0008 — Serialise items and files with byte-exact round-trip fidelity

## Context

The files are hand-edited. A tool that reformats on every write makes its diffs
unreadable and destroys the property that makes this format worth using.

## Requirements

- Parse then write an unchanged file and the bytes must be identical. This is
  the acceptance test, and it is cheap to run over every fixture.
- Preserve: blank lines, prose paragraphs, HTML comments, section spacing,
  unknown frontmatter keys, and the trailing newline.
- Never reformat a line that did not change.
- Canonical field order (format spec §6.1) applies only to lines already being
  rewritten, never as a normalisation pass over a whole file.
- Never reorder `## Ready`. Its order is user intent.
- A no-op operation writes nothing at all — no file touched, no mtime bumped,
  no diff under version control.
- `updated:` in frontmatter is set to today only in files the operation actually
  writes.
