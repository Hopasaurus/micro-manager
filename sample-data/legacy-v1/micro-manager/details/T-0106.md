# T-0106 — Clicking "Note" on the dots menu presents this error: "a note needs some text"

## Notes

**2026-07-31** — Same root cause family as T-0105: mm.js posted note as a one-shot operation with no body, and the handler requires text, so the entry could only ever fail. Fixed per spec-gui.md 7.2, which routes --note through item-notes rather than a dialog: the note entry now carries the same hx-get as edit and move and opens the panel, where the text is typed. Considered a dialog-note prompt instead (consistent with block/finish) but the spec assigns those to prompts and note to item-notes, and a new dialog would add a DOM contract the spec does not define.

TestCardMenuPanelOpsOpenThePanel extended to cover note; verified it fails without the attributes. Confirmed live: Note opens the panel and a typed note landed dated in details/T-0001.md.
