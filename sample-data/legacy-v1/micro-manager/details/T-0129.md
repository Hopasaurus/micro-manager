# T-0129 — Morph the board, status and check refreshes (hx-swap=morph)

## Context

`research-app-fllicker.md` §2 sources 1–3: the 30 s backstop re-renders a
quiescent tab, every refresh tears down the whole board, and a mutation is
followed within 5 s by an SSE-triggered refetch of the identical board. All
three become invisible when the swap diffs instead of replaces.

Requires idiomorph on the page (T-0128). Where idiomorph is absent htmx falls
back to the plain swap, so this change degrades safely.

## Requirements

- Change the region refreshes from `hx-swap="outerHTML"` to `hx-swap="morph"`:
  - `templates/partials/board.html` — the board (`sse:board` + `every 30s`)
  - `templates/board.html` — the `app-status` footer (`sse:status` + `every 30s`)
  - `templates/check.html` — the check view (`sse:check` + `every 30s`)
- ~~Change the mutation swaps to morph as well~~ — **reverted by [[T-0138]]**.
  This was shipped and then undone: morphing the board from an element outside
  it leaks an htmx polling chain per mutation, because htmx stops the old
  `every 30s` chain only when the swapped-out element leaves the DOM. The
  `htmx.ajax` calls in `static/mm.js` and the board-targeting swaps in
  `templates/partials/dialogs.html` and `templates/partials/item-panel.html`
  are `outerHTML` again. T-0130's echo suppression covers the double-swap this
  clause was meant to hide. OOB swaps (`hx-swap-oob`) were never affected.
- **Keep the `every 30s` backstop** (report option D1): under morph it stops
  flickering and stays as the dead-stream guarantee. Do not remove it here.
- The server emits identical bytes — only the client's swap verb changes, so
  fragment parity (T-0054) and the DOM contract are untouched.
- Update any test that asserts `outerHTML` on these regions (grep the web tests;
  `sse_test.go:285` asserts trigger strings only and should be unaffected).
- Test mode (§4.4) and `prefers-reduced-motion` (§11.6) are not animation:
  morphing is a swap strategy and must keep working in both.

## Open questions

  separate because the shell is the one place morph cost could bite.
