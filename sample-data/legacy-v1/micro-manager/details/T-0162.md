# T-0162 — Open the new-item panel through an htmx swap like the card title link

[[T-0148]] (spike, 2026-08-04) found the + link is the one board path that
still full-page-loads. The card title links (`partials/item-card.html`) are
progressive enhancement: `href` for no-JS plus `hx-get` into
`#item-panel-root` with `hx-push-url="true"`, so opening an item detail swaps
the panel over the live board. The column add links
(`partials/board.html:44`) are plain anchors to `/p/:id/new` — a full
navigation that re-renders the whole app (white flash, scroll reset, SSE
reconnect) every time someone starts an item.

Give the add link the same treatment: `hx-get` the panel URL (including the
`?section=` query the href already carries), `hx-target="#item-panel-root"`,
`hx-swap="innerHTML"`, `hx-push-url="true"`, keeping the `href` for no-JS.
The server already renders the panel-only fragment for htmx callers
(`wantsFragment`), so no server change is expected. spec-gui.md does not pin
the add link as a plain anchor.

Deliberately separate from T-0161: this removes the last full-page load on
the board, but it is a navigation-quality fix, not a data-region flicker.

## Resolution (2026-08-05)

Done as specified — a template-only change, as the detail expected. The
column add links in `partials/board.html` now carry the card-title trio
(`hx-get` / `hx-target="#item-panel-root"` / `hx-swap="innerHTML"` /
`hx-push-url="true"`) alongside the unchanged `href`, and the `hx-get` URL
carries the same `?section=` the href does, so the new-item form is still
seeded (§5.6) whether the click swapped or navigated. `wantsFragment` already
served the panel alone for the htmx caller, so no server change was needed.

The working column keeps no add link, and `spec-gui.md` needed no change (the
add link's testid is contract; its being a plain anchor was not).
`TestColumnAddLinksSwapThePanel` pins the attributes, the href/hx-get parity,
and the swap contract (an htmx GET of the link's URL returns the panel
fragment without the app shell, form seeded with the section).
