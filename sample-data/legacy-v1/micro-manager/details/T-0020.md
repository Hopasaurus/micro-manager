# T-0020 — Implement finish with month group insertion

## Notes

Finish is the first operation that inserts into `done.md`, and it surfaced two
latent bugs in the insert helpers written for T-0008 and T-0017 — both invisible
until something actually used them:

- `doneFile.InsertItem` rendered the item line **before** setting `State` to
  done. The box is a function of the file an item lives in, so every inserted
  line came out `- [ ]` and the transaction's own validator rejected it with I3.
  Both `InsertItem` helpers now set state and section first, then render.
- `insertPos` put the first item of an empty group directly under the heading,
  above the `<!-- No completed items yet. First one goes directly below this
  line. -->` placeholder that the sample directories ship with — leaving a file
  that contradicted itself. It now skips leading blank and HTML-comment lines
  when the run is empty.

Neither had a test because nothing had inserted into `done.md` before. Both are
covered now.
