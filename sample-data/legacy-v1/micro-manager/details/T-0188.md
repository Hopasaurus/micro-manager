# T-0188 — Spec: --describe TEXT, the board description in --status, and --init --description (spec-tools.md)

The pi plugin's board description (spec-pi-mm-plugin.md §3.4) reads and writes
through `mm`; spec-tools.md currently has no surface for it. Three additions:

1. `--status` (§5.2): the JSON envelope gains `description` — the first
   paragraph of the directory's `structure.md` (spec-file-format.md §5.5:
   free prose, optional, never validated); absent file/paragraph means the
   field is absent, not an error. Human output MAY show it.
2. A new optional operation `--describe TEXT` (§5.3): writes or replaces the
   first paragraph of `structure.md`. The plugin MUST NOT write that file
   itself, so this op is the plugin's only write path (§8.1).
3. `--init` (§5.1.1) gains `[--description TEXT]` (alongside the T-0186
   `--prefix`), so a board is born with its purpose stated in the fresh
   `structure.md`.

All three are additive; nothing existing changes meaning.
