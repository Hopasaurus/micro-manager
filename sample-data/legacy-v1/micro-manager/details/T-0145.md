# T-0145 — Make a way to show all done items

Make a way to show all done items.  This could be a clickable element at the bottom of the list that shows more or could be a different view.

## Resolution (2026-08-05)

Implemented with T-0144 as the clickable element, not a new view: when the
done column is truncated, its body ends with `board-column-done-show-all`, a
link to the addressable state `/p/:projectId/board?done=all` (§4.1, new
`done` query parameter). A link, not an in-place expand, so the state is
addressable (rule 1), survives back/forward (rule 3), and is preserved by the
SSE backstop refresh (the board's `hx-get` carries `done=all` forward). The
link is absent when nothing is hidden; `doneLimit: 0` behaves identically to
`done=all`. A new view was rejected: the board column is where the count
lives, and a second list would have to re-answer filters and ordering that
`?done=all` inherits for free.
