# T-0112 — Write tasks for adding the ability to change the task prefix and set the number of digits for the task number.

Currently all the tasks are prefixed with "T" it would be useful to be able to select that on a per board or even a per task basis.

Currently the tasks are numbered with four digits, it would be useful to select the number of digits.  3-6 digits seems like a useful range beyond that range there may be a suggestion to stay in that range but not a hard stop preventing it.
