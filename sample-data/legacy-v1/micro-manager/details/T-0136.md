# T-0136 — Morph the theme shell swap to preserve focus and scroll

## Context

`research-app-fllicker.md` §3 G. `sse:theme` swaps the whole app element
(`templates/layout.html` — `hx-get="/p/{{.ID}}/shell"`, `hx-swap="outerHTML"`).
It is the one deliberate whole-app replacement and is nearly invisible already:
the resolved tokens are inlined in the served HTML, so there is no flash of the
previous theme. The remaining cost is that focus and scroll are lost on a theme
edit.

Phase 3 polish: optional, only once idiomorph exists (T-0128), and only if a
theme edit measurably loses state.

## Requirements

- Change the shell swap to `hx-swap="morph"` once idiomorph is on the page.
- Verify focus and scroll survive a `sse:theme` swap, and that the inlined
  `<style>` block still re-themes correctly (morphing a changed style element
  must actually apply the new rules).
- Measure the morph cost on the full shell (it carries the style block, the
  nav, and the panel root) before committing to it — this is the one place
  morph could be slower than replace.
- The app-root attributes (`data-busy`, `data-theme-*`, `data-project-id`) are
  server-emitted and must stay accurate after a morph.
