# T-0284 — Fix task detail resizing, sticky header, and dismissal

## Requirements

1. Extend the resize handle to the full height of the task detail item. It currently only spans the view window and scrolls out of reach; resizing must remain available no matter where the page is scrolled.
2. Add a header at the top of task detail that stays pinned to the top while scrolling. Show the task ID, description, and stage, plus an X button that closes task detail.
3. Close task detail when clicking outside it.
