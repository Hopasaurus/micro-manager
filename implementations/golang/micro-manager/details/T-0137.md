# T-0137 — Theme preview in theme editor

The theme editor should have a live preview so the user can see what the theme will look like.

Also add a lite mode theme that is built in.

Also add a feature to do automatic color complementing or whatever it is called where a user can pick a color and other colors and shades are selected that look nice with that color and it is somehow based on a color wheel.
