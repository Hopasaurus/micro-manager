# T-0243 — Drag-and-drop moves silently no-op on v2 boards: mm.js never sent stage:

## Notes

Reported live: dragging ready to someday (collapsed) left the item in ready, repositioned. Root cause: commitMove() in mm.js only ever sent values.section, never values.stage; moveV2/pauseV2 default an empty Stage to the item's current stage, so the drop silently became a same-stage reposition. Fixed by sending both fields unconditionally, matching the server's own both-fields convention. No test anywhere had asserted values.stage, so this was untested since the v2 board view first shipped.
