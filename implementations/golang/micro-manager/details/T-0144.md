# T-0144 — Done only shows the count up to the limit

Done only shows the count up to the limit,  it should show the full count of done items. 

may it should show something like "20 of 110" 

## Resolution (2026-08-05)

Implemented with T-0145. The done column now carries `data-total` (the full
count) next to `data-count` (cards rendered), and `board-column-done-count`
reads "shown of total" — `20 of 110` — when the limit hides items, the bare
count otherwise. Spec-gui.md §5.5; `internal/web/board.go`
`buildBoard`.
