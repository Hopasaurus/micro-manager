# T-0022 — Implement init for a new micro-manager directory

## Notes

`Init` is a package-level function, not a `Store` method: there is no directory
to open yet. It validates what it is about to write with the same validator every
mutation uses, so the one thing it cannot do is create a directory that
`--check` would immediately reject.

Decisions:

- **The slot count and `--slot-width W` are checked against each other.** Ten
  slots at width 1 would produce `working.9.md` beside `working.10.md`, which
  I10 forbids and which would quietly name nine slots instead of ten.
  (This switch was `--wip N` when this was written; [T-0030](T-0030.md) renamed
  it to `--slots`, because `--wip N` is an operation and §3.2 gives operations
  and modifiers one namespace. The library field is still `InitRequest.Wip` —
  it names the concept, while the switch names itself.)
- **A project name containing `" #"` is refused.** Frontmatter values are read
  with a trailing comment stripped, so such a name would come back shortened —
  the file would fail to describe itself the moment it was written.
- **The generated idle slot carries no "nothing in progress" prose.** `--start`
  fills the frontmatter and does not rewrite a person's text, so that sentence
  would still be sitting there claiming the slot was free. See [T-0018](T-0018.md).
- `structure.md` is written by default and is self-contained: a generated
  directory has no access to the project's specs, and a format nobody can read
  without a tool is the opposite of the point.

## Two bugs in the write layer, found by using it

Both predate this item and were invisible until something inserted into an empty
section — which nothing did until `--finish` and `--init` existed together:

- **`insertPos` consumed the file's trailing newline.** `splitLines` gives a file
  ending in `\n` a final empty element, and that element *is* the newline; the
  blank-skipping loop stepped past it and appended after the end of the file.
  Every `done.md` written into a fresh month group came out with no final
  newline.
- **Spacing.** An item inserted into an empty section landed directly against the
  next `## ` heading, and after an HTML-comment placeholder with no blank line —
  which does not render as a list. `insertPos` now inserts the separating blank
  lines itself, since the caller only ever writes one line.

Regression-tested in `TestInsertIntoAnEmptySectionKeepsTheFileWellFormed`.
