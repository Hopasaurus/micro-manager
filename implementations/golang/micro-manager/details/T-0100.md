# T-0100 — Make the drop zone for each column extend to the same vertical size as the biggest column

## Notes

**2026-08-01** — Two CSS rules, both required. .mm-board had align-items: flex-start so each column stopped at its own last card; changed to stretch. That alone is not enough: mm.js resolves a drop with closest('.mm-column__body'), so the body itself must fill the taller column or the new slack belongs to the column and is not droppable - hence flex: 1 on .mm-column__body. Collapsed-someday rules already used height:100% and were unaffected.

Measured before/after in a real browser by toggling the rules live: someday with one card had a 77px body and a point 400px down hit nothing; after, the body is 415px (equal to ready's) and the same point resolves to someday. Dropped an item into that formerly dead space end to end - landed in Someday position 2 on disk. Source-shape guard added; verified it reports all 3 failures on a revert.
