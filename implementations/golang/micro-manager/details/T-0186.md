# T-0186 — Spec: add --prefix P to mm --init so a board's id_prefix can be set at creation

`spec-tools.md` §5.1.1 (`mm --init`) names `--project`, `--slots`,
`--slot-width` — but not a way to set the directory's `id_prefix`
(`spec-file-format.md` §3.3.2: one to four uppercase ASCII letters, default
`T`). The pi plugin's `mm_init` (spec-pi-mm-plugin.md §3.3) needs it: a board
should be able to claim its own ID prefix at creation, the one point the
decision can be made cleanly. Add `[--prefix P]` to the §5.1.1 signature and
to the modifiers list, with `InvalidArgument` when the value is not one to
four uppercase letters. No behavior conflict: `--prefix` is an additive
optional switch.
