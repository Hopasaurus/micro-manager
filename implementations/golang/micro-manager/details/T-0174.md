# T-0174 — Implement the pi plugin per project/spec-pi-mm-plugin.md

Implement the plugin `project/spec-pi-mm-plugin.md` specifies: a pi extension
(TypeScript) that brings a micro-manager board into pi as structured tools
(`mm_status`, `mm_next`, `mm_list`, `mm_show`, `mm_board`, `mm_add`,
`mm_edit`, `mm_move`, `mm_start`, `mm_pause`, `mm_finish`, `mm_note`,
`mm_remove`, `mm_check`), a `/mm` command mirror, per-turn context injection,
and session board-pinning with branch support.

The load-bearing rules from the spec: the plugin drives the `mm` CLI
(`--json`, `--dir` pinned, exit-code mapping of §4.3/Appendix C) and MUST
never read or write the board files directly; nothing mutates on its own
initiative; `mm_remove` is guarded twice (`confirmed: true` + `ctx.ui.confirm`
when a UI exists); context injection is ≤ 8 lines and refreshes after a
mutation; the source tree in this repo must NOT be named `micro-manager`
(check.sh would treat it as a todo directory).

Prerequisite to honour: the plugin requires a conforming `mm` on PATH
(spec-tools.md §11) and must degrade loudly but gracefully when the installed
build lacks an operation (exit 2).

**Superseded 2026-08-05** — the single implementation task was broken out into
the Someday tasks T-0175..T-0185, one per spec section, so the plugin can be
built and reviewed in pieces.
