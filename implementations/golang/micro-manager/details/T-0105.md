# T-0105 — Attempting to edit via the context menu does not seem to do anything

## Notes

**2026-07-31** — Root cause: mm.js returned early for edit and move ('the panel owns these'), but the menu entries were plain buttons carrying only data-op/data-item - no href, no hx-get - so nothing at all happened on click. Fixed declaratively rather than in JS: the edit and move entries now carry the same hx-get/hx-target/hx-swap/hx-push-url the card title uses to open the panel, so they work without script and get URL pushing for free. mm.js's early return is now correct and its comment true. Note move is disabled for working and done items, so only backlog items get a live move entry.

TestCardMenuEditAndMoveOpenThePanel added; verified it fails without the attributes. Confirmed live in a browser: clicking Edit in the context menu opens the item panel with the editable form.
