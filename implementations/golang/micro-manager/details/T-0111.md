# T-0111 — Close the drag-behaviour test gap: non-displacing placeholder and/or a JS test runner (T-0110 follow-up)

The "and/or" in the title is resolved: **both halves are now done**, in the
order the detail recommended.

## Option A — non-displacing placeholder: DONE (T-0149)

T-0149 shipped the out-of-flow placeholder (`position: absolute; left: 0;
right: 0; pointer-events: none` in mm.css, `style.top` positioning in
mm.js's `hoverTarget`). The T-0110 feedback loop — inserting the placeholder
shifted the card under the pointer, so the next dragover measured while it was
still there — cannot exist: the placeholder displaces nothing. The superseded
source-shape guard is `TestPlaceholderIsOutOfTheColumnFlow`. A (the structural
fix) also removed the need for the clear-before-measure ordering the old guard
protected, and its browser verification is recorded in T-0149.

## Option B — JS test runner: DONE (this item)

`internal/web/jstest/` is a real behavioural suite for the real mm.js:

- **Tooling.** Node's built-in `node --test` runner + jsdom (the light runner
  the detail argued for). The Go test `internal/web/client_test.go` drives
  it, so `go test ./...` remains the single entry point; it skips when node
  or jsdom is missing, exactly as the check.sh cross-check skips when bash is
  missing — and it asserts the TAP summary reports tests RAN, so a silently
  empty suite fails.
- **What runs.** mm.js executes against a jsdom document with a double for
  htmx (records `ajax` calls, fires `htmx:*` events). 24 tests: data-busy
  counting, the T-0130 echo-window cancellation, card menus (open/close/
  outside-click), the item-menu ops (post, dialog fetch, panel-ops-left-to-
  hx-get, disabled-does-nothing), dialogs (Escape closes + focus restore,
  Tab trap both directions), toast auto-dismiss + test-mode exception,
  clipboard copy, drag start/dragover/drop/end with synthetic geometry
  (details/T-0141's prescription: drive events explicitly, assert the §7.3
  attributes), the keyboard move mode, and — the newest code — T-0139's
  SSE-down polling.
- **What it cannot catch.** Layout-coupled bugs (T-0110's class): jsdom
  measures nothing. Those are prevented structurally (Option A) rather than
  tested behaviourally, per the detail's "which to reach for next time".

## Costs, recorded

- New toolchain in a Go repo: `internal/web/jstest/package.json` +
  `package-lock.json` (jsdom devDependency), node_modules gitignored.
  jsdom is not embedded: `go:embed` covers only `static` and `templates`,
  and the suite lives outside both. One new Go test, one skip path.
- mm.js grew past the 720-line ceiling; the guard is now 780 with the
  T-0139 reason in its comment.
