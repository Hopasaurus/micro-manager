# T-0255 — Audit log: show the item title between id and field

Requested: a new description column between the item ID and the field
name, width-limited with ellipsis, full text on hover.

## Fix

UI-only, as clarified — `audit.md` itself gains nothing: it stays exactly
`TIMESTAMP | id:ID | field:NAME | value:VALUE` (format spec §5.7). The
title is looked up live, once per distinct ID per render (not once per
line — the same item commonly repeats across consecutive entries), via
`Store.Get`.

- `internal/web/audit.go`: `auditEntryData` gained `Title`; `buildAudit`
  resolves it through a small per-request cache. An ID that no longer
  resolves (a removed item) gets an empty title rather than an error —
  the log is a history, and a since-removed item still gets its past
  entries shown.
- `internal/web/templates/audit.html`: a `.mm-audit__desc` span between
  the id link and the field pill, `title="{{.Title}}"` for the native
  hover tooltip; an empty title falls back to the same blank-value
  placeholder (em dash) already used for a blank field value.
- `internal/web/static/mm.css`: `.mm-audit__entry`'s grid gained a
  `minmax(0, 16rem)` column for it — the `0` minimum is what actually lets
  `text-overflow: ellipsis` bite; a bare `16rem` alone doesn't shrink
  below the content's own width in a CSS grid track.

## Tests

`internal/web/audit_view_test.go`: `TestAuditViewShowsItemTitle` (title
rendered with the same text in `title=` for hover) and
`TestAuditViewBlankTitleForARemovedItem` (a removed item's row falls back
to the blank placeholder rather than erroring or going empty-string bare).

Verified live: added a deliberately long title in a running browser,
confirmed it truncates with an ellipsis in the column, and read the full
text back off the element's `title` attribute (the mechanism a native
hover tooltip actually uses).

`go build`, `go vet`, `gofmt -l`, and the full `go test ./...` are all
green.

## Notes

Item title now shows between id and field in the audit log, truncated with ellipsis and the full text in a title= attribute for native hover. UI-only, per the user's own clarification - audit.md's own format is unchanged.
