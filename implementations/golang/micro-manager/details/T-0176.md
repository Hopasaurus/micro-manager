# T-0176 — mm runner: subprocess with --json, --dir pin, timeout, exit-code mapping

From [[project/spec-pi-mm-plugin.md]]. The shared runner of spec §4.1 and Appendix C: one mm subprocess per tool, always --json, --dir once pinned, bounded timeout (default 30s, config timeoutMs), exit codes 0-6 mapped to typed tool errors with remedies surfaced (WIP slots on 4, re-read instruction on 5, "operation not in this mm build" on 2). Never retry a failed mutation automatically.
