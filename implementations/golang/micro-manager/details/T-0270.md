# T-0270 — Add an option to pause tickler tasks

Add per-item tickler pausing in the backend and expose it in the item editor.

## Decisions

- Pause applies to one scheduled item, not the global tickler service.
- Resume waits for the next future occurrence instead of replaying anything missed while paused.
- A one-shot whose fixed date passed while paused is spent when resumed; it does not fire late.

## Implementation

- `tickler_paused:true` preserves a schedule while suppressing its due state and all tick runs.
- Removing `tickler_paused` through the backend update operation stamps `tickled:<today>` as the new schedule baseline.
- Tickler listings expose paused state and never report a paused item as due.
- The item editor has a pause checkbox. Board cards show a `paused` badge and `data-tickler-paused="true"`.
- Moving or finishing an item where its schedule must be removed also removes paused state.
- The file-format, tools, GUI, generated `structure.md`, and JSON item representation document/expose the field.
