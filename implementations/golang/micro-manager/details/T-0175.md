# T-0175 — Plugin skeleton and install: directory extension, package.json, mm-on-PATH check

From [[project/spec-pi-mm-plugin.md]]. Build the directory-form extension per spec §2, §3.1: index.ts factory, helper modules, typebox + pi packages only. Verify mm on PATH at session start and degrade loudly but gracefully when absent (tools error, no context injection, name what to install). Source dir in this repo must NOT be named micro-manager (check.sh treats it as a todo directory); the installed copy in pi's extension dir is named micro-manager.
