# T-0203 — AGENTS.md: refresh the stale Current state and its neighbours

The orientation file an agent reads FIRST had drifted several sessions behind
the tree, which is the worst place for a stale claim: it is believed before
anything can contradict it.

What was wrong:

- "Go library: T-0001 … T-0017 shipped" and "28 tasks remain, next is T-0018" —
  167 items are done and the top of Ready is T-0191.
- "No working CLI. cmd/mm returns exit 2." — the CLI is complete, including the
  optional operations, and `mm` is what this repository now tracks its own work
  with.
- "No GUI or TUI code." — the UI service of spec-gui.md is built
  (internal/web, cmd/mm-ui). The TUI is still unwritten, which is the half of
  that sentence worth keeping.
- "T-0040 is blocked … no VCS remote. `git init` would unblock it." — T-0040
  shipped on 2026-08-04; go.mod says github.com/Hopasaurus/micro-manager.
- "mmx is the tracking stopgap until `mm --start`/`--finish` exist." — they
  exist. mmx stays the default because it needs no build and is permitted
  without prompting, but the reason had to change.
- "T-0029 adds one" for the library-hygiene test — shipped 2026-07-30; the test
  is mm/hygiene_test.go, and it parses rather than greps.
- The LSP section's "most of mm/'s exported surface has zero callers because
  the CLI and the UI service are not written yet" — both are written.
- The layout block described cmd/mm as a stub, gave a line and test count for
  mm/ that had moved, and did not mention internal/web, cmd/mm-ui or plugins/.

The structure and voice are unchanged: this is a rewrite of the claims, not of
the document.
