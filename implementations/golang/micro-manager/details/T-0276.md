# T-0276 — Add optional Vim keybindings to the CodeMirror detail editor

Follow up to T-0275 after the base CodeMirror Markdown editor is stable and its bundle size is recorded.

Use the MIT-licensed `@replit/codemirror-vim` extension: https://github.com/replit/codemirror-vim

Scope:

- Add the extension as an exact, locked dependency in the CodeMirror asset build and record its separate compressed and uncompressed bundle-size cost.
- Expose Vim mode as an explicit global user preference; standard CodeMirror bindings remain the default.
- Support toggling without losing the document, selection, scroll position, or undo history.
- Provide a visible and screen-reader-announced mode/status surface for NORMAL, INSERT, VISUAL, and command input.
- Define and test collisions with application Save, Preview, panel-close/Escape, and search shortcuts.
- Preserve the native textarea fallback and ensure Vim state is destroyed with the CodeMirror view during htmx cleanup.
- Cover core modes, motions, operators, counts, registers, repeat, search, mappings, and supported Ex commands without claiming complete native Vim parity.
- Do not implement Vim behavior locally; use the selected extension and document any unsupported commands discovered during verification.

Dependency: do not begin until T-0275 has established the CodeMirror factory/lifecycle API and baseline bundle measurement.
