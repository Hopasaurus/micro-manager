# T-0107 — I deleted a duplicate ticket using the context menu then later started seeing this: "I9 details/T-0102.md orphan — no item references it"

## Notes

**2026-07-31** — Root cause: internal/web/item.go removeItem discarded the Removal and never passed WithDetail, so the UI did neither of the two things spec-tools.md 5.1.6 requires (delete the file, or report the orphan). The confirm dialog even promised the wrong thing - 'a detail file it points at stays where it is'. Fix: dialog offers an x-prefixed checkbox, checked by default (the only branch leaving the directory valid), shown only when the item has a detail file; the handler passes WithDetail and turns DetailDeleted/DetailOrphan into the toast, warning severity for the orphan. Verified live in the browser: htmx 2.0.7 appends DELETE params to the query, so the checkbox reaches the handler.

3 tests added (delete/keep/dialog); verified they fail against the old handler with the exact reported symptom. Confirmed end to end in a real browser against a throwaway copy: checked leaves the directory clean, unchecked warns and check reports the orphan.
