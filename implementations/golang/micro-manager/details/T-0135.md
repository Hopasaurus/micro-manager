# T-0135 — CSS transition polish on swap (fade .htmx-added content)

## Context

`research-app-fllicker.md` §3 F. A short fade-in on `.htmx-added` makes even a
coarse swap feel intentional. Presentation only — it does not fix focus or hover
loss (that is T-0129's morph) and it can *add* perceived motion if overdone.

Phase 3 polish: only if Phase 1 (T-0128–T-0130) still feels abrupt.

## Requirements

- Transitions keyed off htmx's swap-phase classes (`.htmx-added`), with a
  `hx-settle-delay` where needed, in `static/mm.css`.
- Both existing disable paths keep working: `prefers-reduced-motion` (§11.6)
  and test mode (§4.4) must still suppress all animation.
- No change to layout, locators, or `data-*` attributes — the DOM contract is
  untouched.
