# T-0164 — Tickler service

Define a way for a task to be placed into 'someday' with a date in the future when a service will move it to the ready column.

Also define a way for repeatable items to be created that are a prototype that create a task in the ready column.

The move/create date can be a specific date (perhaps with optional time) or a specification such as 'first Monday of the month' or 'Monday at 8am'. Spike this out first with a proposed spec.  This does not need to be free form text in the UI but could be a set of controls to make parsing easier and more consistent.


How this should be triggered should be defined.  It should be part of the library and either the mm-ui can trigger it if that is always running, or mm can have a cron entry or a systemd timer.  The implementation should be flexible enough to define both.
