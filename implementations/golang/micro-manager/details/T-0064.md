# T-0064 — Build the theme editor, library, import and export

## Context

Loading and resolving themes is the library's job (see the config-and-theme
item). This is the surface over it: `/settings/theme`, `/settings/themes`,
`/settings/themes/:themeId`, and the import/export endpoints — plus the styling
discipline that makes a theme portable across implementations.

The goal in `spec-gui.md` §8.1 is worth restating because it drives the design:
**the look of the screen tells the user which project they are in before they
read a word.**

## Requirements

1. Every `color` and `gui` token is emitted as a CSS custom property on the app
   root, named by lowercasing the path and replacing `.` with `-`
   (`color.bg.base` → `--mm-color-bg-base`, `gui.space.3` → `--mm-space-3`).
   Appendix B is the complete index and a test asserts every one is present.
2. `mm.css` **MUST NOT hard-code a colour that a token covers** (§8.4). This is
   externally testable — the suite reads the computed value of
   `--mm-color-accent-base` and asserts the element uses it — so a grep for
   `#rrggbb` in the stylesheet outside the fallback block belongs in the audit
   test.
3. Properties are inlined in the served HTML rather than fetched, which makes
   "no flash of the previous theme on project switch" (§8.7) true by
   construction rather than by timing.
4. `data-theme-name` and `data-theme-source` (`project`|`system`|`builtin`) on
   the app root, updated on every project switch.
5. The editor applies live to the current view — it is a preview, not a form
   with a save button that reveals the result afterwards (§8.7).
6. Import (§8.8) must: reject an unimplemented `schemaVersion` naming the
   version; validate every colour value and report each bad token **by path**;
   never partially apply; preserve unknown keys; and on an `id` collision
   require an explicit overwrite-or-rename choice through `dialog-import-theme`.
   The destination — library, system, or the current project — is an explicit
   parameter with **no default**.
7. Export emits one self-contained file with every asset inlined as a data URI,
   filename `<themeId>.mm-theme.json`, `Content-Disposition: attachment`.
8. Contrast: warn when `fg.default`/`bg.base` or `accent.fg`/`accent.base` fail
   WCAG AA 4.5:1. **Warn, never block saving** (§11 rule 7).
9. `appearance: auto` requires both `color` and `colorDark` and follows
   `prefers-color-scheme`; the dark set is emitted inside a media query rather
   than swapped by script.
10. `brand.ascii` is the TUI's mark and is ignored here; `brand-logo` carries
    `alt=""` whenever `brand-name` is displayed beside it (§8.6).
